# Wandr — Trip Planner

A Firebase-powered collaborative trip planning web app.

## Local development

```bash
npm install
npm run dev
```

**Live URL:** https://sanjid-sharaf.github.io/wandr/

## Stack

- Vite + React 18
- Firebase 10 (modular SDK)
  - Firestore (real-time trips sync)
  - Authentication (Google sign-in)
